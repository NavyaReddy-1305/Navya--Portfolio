## 💻 Featured Projects

### 🩺 HealthSync AI – Personalized Healthcare Assistant
A multimodal AI-powered healthcare assistant that integrates medical reports, radiology images, clinical notes, patient symptoms, and physiological sensor data to deliver personalized healthcare insights. The system leverages Retrieval-Augmented Generation (RAG) to perform medical report summarization, disease prediction, risk analysis, and explainable healthcare recommendations.

### ✈️ TripNavigator – Agentic AI Travel Planner
An intelligent travel planning application that uses multiple AI agents to generate personalized travel itineraries based on user preferences, budget, accommodation, transportation, and attractions, delivering a seamless trip planning experience.

### 🤖 Mint AI Projects
A collection of AI-powered applications developed during my internship at Mint, demonstrating practical implementations of Large Language Models, Retrieval-Augmented Generation (RAG), intelligent automation, and real-world AI workflows.
